☁️ Google Cloud (YouTube)

1 Go to console.cloud.google.com/apis/credentials
2 Click "+ Create Credentials" → "API Key" → Copy it
3 Click "+ Create Credentials" → "OAuth Client ID"
4 Select "Web application" → Name "Blank Log"
5 Add https://blank-log.vercel.app to Authorized origins
6 Click "Create" → Copy Client ID and Secret

📸 Meta (Instagram)

1 Go to developers.facebook.com
2 Click "My Apps" → "Create App" → Select "Business"
3 Name "Blank Log" → Click "Create App"
4 Go to "Settings" → "Basic" → Copy App ID and App Secret
